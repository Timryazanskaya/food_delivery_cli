## Food Delivery CLI
Консольное приложение сервиса доставки еды, разработанное в рамках проектной практики.

---

## О проекте
Food Delivery CLI — это консольная система, моделирующая работу сервиса доставки еды.

Приложение реализует взаимодействие между:
- клиентами;
- ресторанами;
- курьерами.

Проект разработан с использованием языка Python и работает в CLI-режиме (Command Line Interface).

Система поддерживает:
- регистрацию и авторизацию пользователей;
- оформление заказов;
- управление меню ресторанов;
- обработку доставки;
- сохранение данных между сессиями.

---

## Основной функционал
### Клиент
- Регистрация и вход в личный кабинет
- Просмотр меню ресторанов
- Добавление блюд в корзину
- Оформление заказа
- Просмотр истории заказов
- Отмена заказа
- Отслеживание статуса заказа

### Ресторан
- Авторизация
- Управление меню:
  - добавление блюд;
  - удаление блюд;
  - редактирование блюд.
- Просмотр заказов
- Изменение статуса заказа
- Просмотр статистики

### Курьер
- Регистрация и вход
- Просмотр доступных заказов
- Получение заказов
- Изменение статуса доставки
- Просмотр статистики

## Хранение данных

Для хранения информации используются текстовые файлы в формате JSON.

Данные сохраняются в директории data/:
- `users.txt` - хранение пользователей;
- `orders.txt` - хранение заказов;
- `restaurants.txt` - хранение меню ресторанов.

Система автоматически загружает данные при запуске приложения.

---

## Технологии

- Язык: Python 3.14.3
- Интерфейс: CLI (консоль)
- Хранение данных: JSON (через текстовые файлы)
