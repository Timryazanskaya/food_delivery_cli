## Описание
Приложение моделирует работу сервиса доставки еды с тремя ролями:
- Клиент
- Ресторан
- Курьер

Реализовано взаимодействие между участниками процесса:
оформление заказов, управление меню, доставка.

---

## Функциональность

### Клиент
- Регистрация и вход
- Просмотр заказов
- Добавление блюд в корзину
- Оформление заказа

### Ресторан
- Управление меню (добавление/удаление блюд)
- Просмотр заказов
- Изменение статуса заказа

### Курьер
- Просмотр доступных заказов
- Принятие заказа
- Завершение доставки

---

## Хранение данных

Данные сохраняются в текстовые файлы в формате JSON:
- `data/users.txt`
- `data/orders.txt`
- `data/restaurants.txt`

Это обеспечивает сохранение информации между запусками программы.

---

## Технологии

- Язык: Python
- Интерфейс: CLI (консоль)
- Хранение данных: JSON (через текстовые файлы)
